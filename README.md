# 🛡️ CyberCouncil

**CyberCouncil** is a powerful, user-centric platform that bridges the gap between cybersecurity awareness and cyber law literacy in India. Designed to empower both individuals and law enforcement agencies, CyberCouncil offers practical security tools and legal insights to tackle the challenges of the digital age.

---

## 🌐 Live Website

👉 [Visit CyberCouncil](https://cybercouncil.netlify.app)  


---

## 🔍 Project Overview

In today’s digital world, cyber threats and legal ignorance often go hand in hand. CyberCouncil aims to solve this by:

- Providing **essential cybersecurity tools** to detect and prevent online threats.
- Delivering **up-to-date information on Indian Cyber Laws**.
- Supporting **investigators and police departments** with digital forensics and investigation tools.
- Promoting **digital safety and legal awareness** across communities.

---

## 🚀 Features

### 🧑‍💻 For Individuals

- 🔗 **Phishing Detection** – Identifies suspicious URLs and fake websites.
- 📶 **WiFi Security Checker** – Analyzes network security risks.
- 🔐 **Password Strength Analyzer** – Evaluates password strength and provides improvement tips.
- 🎭 **Social Engineering Detection** – Flags patterns of psychological attacks.
- 📷 **Image Metadata Viewer** – Analyzes EXIF data in images.
- 🔒 **Privacy Analyzer** – Assesses apps or websites for privacy risks.
- 🛡️ **Malware Scanner** – Scans file metadata and detects suspicious behaviors.

### 🕵️‍♂️ For Law Enforcement

#### Tool-Dashboard for Police

- 🧬 **File Hash Generator** – Generates MD5/SHA256 hashes for digital evidence.
- 🗃️ **File Metadata Analyzer** – Extracts forensic details from files.
- 📷 **Image Metadata Viewer** – Analyzes EXIF data in images.
- 🔍 **File Type Validator** – Verifies file content against extension mismatches.
- 🔎 **Username Lookup** – Tracks usernames across platforms.
- 🌐 **URL Live Status Checker** – Checks if a link is active or down.
- 💻 **User IP Display** – Retrieves client IP for activity tracing.
